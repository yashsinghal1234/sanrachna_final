# RFI Examples

RFI means Request for Information. It is used when site teams need clarification.

Example RFI:
Title: Clarification needed for beam reinforcement
Question: Drawing S-204 shows 16mm bars, but site revision note mentions 20mm bars. Please confirm final bar diameter.
Priority: High
Status: Open

Good RFIs should include:
- Clear title
- Drawing/reference number
- Exact question
- Priority
- Required response date
