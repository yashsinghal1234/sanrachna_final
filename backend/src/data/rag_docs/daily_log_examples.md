# Daily Log Examples

Daily logs record site progress, manpower, weather, completed work, delays, and safety observations.

Example daily log:
Date: 2026-06-13
Workers present: 24
Work completed: Column shuttering and slab reinforcement checking
Issues: Material delivery delayed by 2 hours
Safety: No incident reported

Good daily logs should include:
- Date
- Labour count
- Work completed
- Delays
- Issues
- Photos if available
